never modify `~/Herd/emranspace` from here.

- Served by Herd at http://elitehub.test
- Palette: navy `#0B1F3A` + gold `#D4AF37`, light background
- Homepage = Command Center dashboard (KPIs, Operations Hub event islands, live alerts,
